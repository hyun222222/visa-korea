# PDF to WordPress Automation - User Manual

안녕하세요! 이 문서는 변호사님을 위해 제작된 **'판결문 자동 포스팅 프로그램'** 사용 설명서입니다.
코딩을 전혀 모르셔도 순서대로만 따라하시면 됩니다.

## 1. 준비물
시작하기 전에 아래 3가지가 준비되어 있어야 합니다.
1. **Python 설치**: 컴퓨터에 파이썬이 설치되어 있어야 합니다. (설치 안 하셨다면 [여기](https://www.python.org/downloads/)에서 다운로드 후 설치해주세요. 설치 시 "Add Python to PATH" 체크박스를 꼭 체크하세요!)
2. **Google API 키**: 제미나이를 쓰기 위한 열쇠입니다. ([여기서 무료 발급](https://aistudio.google.com/app/apikey))
3. **워드프레스 앱 비밀번호**: 블로그에 글을 올리기 위한 전용 비밀번호입니다. (워드프레스 관리자 페이지 -> 사용자 -> 프로필 -> Application Passwords 항목에서 생성 가능)

## 2. 설정하기 (딱 한 번만 하면 됩니다)

### 1단계: 폴더로 이동하기
1. 윈도우 탐색기를 열고 `C:\Projects\anti\pdf-to-wordpress` 폴더로 들어갑니다.

### 2단계: 비밀번호 입력하기
1. 폴더에 있는 `env_template.txt` 파일의 이름을 `.env`로 바꿉니다. (이미 `.env`가 있다면 그걸 여세요)
2. `.env` 파일을 메모장으로 엽니다.
3. `GOOGLE_API_KEY=...` 부분에 발급받은 **구글 API 키**를 붙여넣으세요. (기존 OPENAI_API_KEY는 지우셔도 됩니다)
4. `WORDPRESS_URL` 등 나머지 정보도 본인의 블로그 정보로 채워넣고 저장하세요.

## 3. 프로그램 실행하기 (자동화 모드)

1. 터미널 창에 아래 명령어를 입력하고 엔터를 치세요.
```bash
python main.py
```
2. 그러면 **"Monitoring folder: .../input"** 이라는 메시지가 뜹니다. 이제 프로그램이 대기 중입니다.

## 4. 사용 방법 (드래그 앤 드롭)
1. `C:\Projects\anti\pdf-to-wordpress\input` 폴더를 엽니다. (없으면 프로그램이 자동으로 만들어줍니다)
2. 판결문 PDF 파일을 이 `input` 폴더에 **드래그해서 넣으세요.**
3. 프로그램이 파일을 감지하고 자동으로 블로그 글을 작성해서 올립니다.
4. 작업이 끝나면 PDF 파일은 자동으로 `processed` 폴더로 이동됩니다. (에러가 나면 `error` 폴더로 갑니다)

## 5. 결과 확인하기
워드프레스 관리자 페이지의 **'글(Posts)'** 메뉴에 가보시면 **'임시글(Draft)'** 상태로 새 글이 생성되어 있을 겁니다.
내용을 훑어보시고 '발행(Publish)' 버튼만 누르면 끝입니다!

---
**팁**: 프로그램을 끄려면 터미널 창에서 `Ctrl + C`를 누르세요.
