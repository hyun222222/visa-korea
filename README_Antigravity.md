## 📋 사전 준비

### 1. API 키 발급

#### OpenAI API
1. https://platform.openai.com/api-keys 접속
2. "Create new secret key" 클릭
3. 생성된 키 복사 (sk-proj-...)

#### SerpApi (뉴스 검색용)
1. https://serpapi.com 가입
2. Dashboard에서 API Key 확인
3. 월 100건 무료, 이후 유료

#### WordPress Application Password
1. 워드프레스 관리자 로그인
2. 사용자 > 프로필
3. "Application Passwords" 섹션에서 새 비밀번호 생성
4. 생성된 비밀번호 복사 (xxxx xxxx xxxx xxxx)

### 2. 환경 설정

```bash
# 1. 패키지 설치
pip install -r requirements.txt

# 2. 환경 변수 파일 생성
cp .env.example .env

# 3. .env 파일 편집 (실제 API 키 입력)
notepad .env
```

## 🔧 고급 설정

### 카테고리 ID 매핑

워드프레스는 카테고리를 **ID 숫자**로 받습니다.

1. 워드프레스 관리자 > 글 > 카테고리
2. 카테고리명 위에 마우스 올리면 주소창에 `tag_ID=15` 같은 숫자 확인
3. 코드의 `PROMPT_GENERATE_BLOG` 수정:
   ```python
   "categories": [15],  # 실제 카테고리 ID로 변경
   ```

### 모델 변경

비용 절감을 위해 모델 조정 가능:

```python
# 키워드 추출 (현재: gpt-4o-mini)
model="gpt-4o-mini"  # 또는 "gpt-3.5-turbo"

# 콘텐츠 생성 (현재: gpt-4o)
model="gpt-4o"  # 또는 "gpt-4o-mini" (품질 다소 하락)
```

### 검색 쿼리 수정

더 많은/적은 뉴스를 검색하려면:

```python
params = {
    "num": 10  # 기본값, 5-20 사이 권장
}
```

## 🐛 트러블슈팅

### "API 키가 유효하지 않습니다"
- `.env` 파일의 API 키 확인
- OpenAI 대시보드에서 키 활성화 확인

### "워드프레스 업로드 실패"
- Application Password 재생성
- WP_URL이 `/wp-json/wp/v2/posts`로 끝나는지 확인
- 워드프레스 REST API 활성화 확인

### "뉴스를 찾지 못했습니다"
- 판결문에 검색 가능한 키워드(사건번호, 고유명사)가 있는지 확인
- SerpApi 할당량 확인
